# MachonSystem

Система Еврейского университета — кампус «Махон Хамеш».

Проект на [Vite](https://vitejs.dev/) (без фреймворка, vanilla JS).

## Структура

```
├── index.html        # стартовая страница
├── public/
│   └── logo.svg      # статические ассеты (копируются как есть)
├── src/
│   ├── main.js       # точка входа
│   └── styles.css    # стили
├── package.json
└── vite.config.js
```

## Разработка

```bash
npm install
npm run dev
```

## Сборка

```bash
npm run build     # результат в ./dist
npm run preview   # предпросмотр собранной версии
```
