# MachonSystem

Система Еврейского университета — кампус «Махон Хамеш».

## Структура проекта

- `index.html` — стартовая страница
- `styles.css` — стили
- `script.js` — скрипты
- `assets/` — изображения и другие ресурсы

## Запуск

Откройте `index.html` в браузере или запустите простой локальный сервер:

```bash
python3 -m http.server 8000
```

Затем перейдите по адресу http://localhost:8000
